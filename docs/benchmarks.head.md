# ベンチマーク結果

このファイルは `python -m arena.report` が `docs/results/*.json` から生成します（手で編集するのは `benchmarks.head.md` の方）。
取り直す手順: `./run.sh` でサーバーを起動 → `python -m arena.bench blobs` / `python -m arena.bench blocks` → `python -m arena.report`。

## 読み方

- **同じ条件で比べています。** 置き方の列挙と結果のシミュレーションはコードが行い、Jev と相手の LLM には同じ戦略ファイル（同じ特徴量・同じ評価基準）を渡します。Jev は候補ごとに Score を1問ずつ（1リクエスト）、LLM は `{"pick": "pNN"}` を返します。
- **リアルタイムです。** 考えている間もピースは落ち続けるので、回答が速いほど多く置けて、多く攻撃できます。勝敗は「判断の質 × 速さ」の結果で、判断の質だけを見たいときは単独プレイの表を見てください。
- 回答時間はサーバー側で計った実時間（日本からのネットワーク往復込み。Jev のサービスは米国西海岸）。費用は定価 × 実際の使用トークン（Jev: 入力 $0.042 / 100万トークン、出力無料）。
- 試合数は少なく（各モデル2試合）、Jev は同じ入力でもスコアがわずかに揺れるので、同じ seed でも展開は変わります。数%の差は誤差と考えてください。
- どちらのゲームも、コードの評価関数だけで十分強く打てます。これは Jev と LLM を同じ土俵で比べ、問いの立て方を試すための題材です。

以前の実装での計測（モデル別の「穴を作った手の割合」など）は [earlier-results.md](earlier-results.md) にあります。
